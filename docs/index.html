Bienvenido a B++

B++ es un lenguaje de programación desarrollado por Doryan Flores Sánchez como parte de los proyectos de PattitexTEC.

Características

  • Disponible para Windows y Termux.
  • Desarrollo independiente.
  • Versiones para distintas plataformas.
  • Sistema de distribución de librerías.
  • Paquetes de librerías en formato .tar.zst.

Librerías de B++

B++ dispone de un sistema de paquetes para distribuir librerías.

Formato de paquetes: .tar.zst

Los paquetes pueden contener un manifest.json y los archivos necesarios para cada librería.

Desarrollo

Desarrollador: Doryan Flores Sánchez.

Proyecto: PattitexTEC.

B++ es un proyecto independiente creado para desarrollar un lenguaje y un ecosistema de herramientas propios.

Dato histórico
